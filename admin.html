Token de GitHub

¿Cómo creo el token?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. En “Repository access” elige solo el repo de tu web.
  3. En “Permissions → Repository” pon Contents: Read and write.
  4. Copia el token y pégalo aquí.
